## Man pages (first-class)

- Every workspace tool under `tools/` has `man/man1/<tool>.1`.
- Also: `recover.sh.1`, `blocktools.1`, overview `man/man7/blocktools.7`.
- Required sections: NAME, SYNOPSIS, DESCRIPTION, OPTIONS, INPUT/OUTPUT, EXIT STATUS, EXAMPLES, SECURITY NOTES, SEE ALSO.
- Generated by `scripts/gen-man.py` from release `--help` + source headers; CI-checked.
- Packaged under `/usr/share/man` in DEB, RPM, APK and the release tarball (`share/man` + top-level `man/`).

## Checks enforced in CI

1. Every `tools/*` name appears in README/DESIGN/EXPORTS/docs/recipes.
2. No hard-coded test counts in README/DESIGN/SECURITY.
3. Built tools are never called "planned".
4. Host network tools excluded from Dockerfile / sealed-run allowlist.
5. Man pages not stale (`gen-man.py --check`).
6. `RUSTDOCFLAGS='-D warnings' cargo doc -p blocktools --no-deps` (facade rustdoc clean).

## Measured vs untested (this pass)

Measured: docs-check; man-check; facade `cargo doc -D warnings`; packaging install-tests (DEB/RPM/APK) include gzipped man pages.
Untested: human readability review of every man page; macOS/arm64 man install; crates.io/npm publish of docs.

## Documentation pass, 2026-10-25 evening

Review of SwapChan's drafts (`/workspace/handoff/docs-draft/`, written at 4949027):

- **EXPORTS-reference.md (draft, 894 lines): replaced by a generated file.** Replaying its 55 examples
  against the wasm built at a15504d: 32 matched exactly, 10 matched only as a prefix (output cut in the
  draft), and 13 could not run at all because their arguments were cut at 200 characters
  (buildUnsignedSweep, buildUnsignedSweepAt, checkTx, checkTxPolicy, decodeTx, describeTx, selectUtxos,
  serializeNvcTxFromJson, solDecodeTx, solVerifyTx, tronBuildTransfer, tronDecodeTx, tronTxId, verifyTx).
  A hand-copied reference also drifts. `docs/EXPORTS-reference.md` is now generated by
  `bindings/wasm/gen-reference.mjs` from the calls test.mjs makes, with full arguments, and
  `scripts/wasm-check.sh` fails when it is stale. test.mjs now also calls `describeTx` and
  `convertAddressFrom` (previously never called) and boundary-tests every input limit the reference quotes.
- **C ABI / envelope table: adopted** into EXPORTS.md after re-running the draft's requests through
  `bt_envelope` (C, Linux) and `tx-envelope`.
- **RECOVERY-GUIDES.md: not adopted.** Every command in it is a verbatim copy of a `recipes/*.md` line,
  and those recipes are already executed by `scripts/recipe-check.py` in e2e. A second copy would drift
  without a check; docs/cookbook.md and docs/README.md link the recipes instead.
- **gaps.md: recorded below.**

Open gaps (not fixed in this pass):

1. Envelope `verify` says `findings`, wasm `verifyTx` says `failures` for the same check. Documented; not unified.
2. macOS: tty session pinning returns `no_controlling_tty_session` (fix pending), `fetch-fixtures.sh`
   needs GNU `sha256sum`, zec-sapling under bash 3.2. Everything in this pass was run on Linux only.
3. `chainTable` rows carry `buildable`; embedders such as SwapChan must not display it as "supported".
4. `bt_free(NULL)` and the macOS `.dylib` are not exercised.
5. Token-2022 mints with extensions are not flagged by `solVerifyTx` yet (see SwapChan's PYUSD report).
